# davidochukoyaya.com

Personal site for David Ochuko Yaya. Static HTML, ready for Netlify.

## Local

Open `index.html`, or:

```bash
python3 -m http.server 4173
```

Then visit http://localhost:4173

## Netlify

1. New site from this repo (or drag the folder).
2. Publish directory: `.` (already set in `netlify.toml`).
3. Point `davidochukoyaya.com` DNS at Netlify once the domain resolves.
